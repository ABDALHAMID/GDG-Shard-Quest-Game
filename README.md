# GDG Drone Adventure

A 3D third-person Unity game where the player controls a hero tasked with collecting **GDG Shards** while avoiding and combating enemy drones. This project demonstrates core game development concepts including movement, AI, shooting, health systems, and obstacle avoidance in Unity.

## Gameplay

The player explores a 3D environment to collect shards while avoiding enemy drones. Drones patrol areas, chase the player when detected, and shoot projectiles when within attack range.  

---

## Features

- Third-person player controller  
- Enemy drone AI with:
  - Patrolling  
  - Player detection  
  - Projectile attacks  
  - Obstacle avoidance  
- Health system for player and enemies  
- Visual health indicators (UI for player, world-space for enemies)  
- Shooting system with visual effects for hits
